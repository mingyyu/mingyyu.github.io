  5. Conversational Shopping Agent

    A deterministic, multi-turn shopping agent that finds a hidden target product within ten turns across a 50,000-item catalogue. Uses intent routing, multi-route lexical retrieval, adaptive reranking, and structured clarification in standard-library Python. About

I study Computer Science at NUS and like building things other people can open and use.

Much of my recent work came out of a busy run of hackathons (LifeHack, PSA Code Sprint, TikTok TechJam, NiCE Hack, the Tencent Cloud Hackathon, and the NUS CFG x Garena Roblox hackathon), alongside a machine-learning forecasting competition I’m entering solo right now. Across all of them, the parts I enjoy most are the unglamorous ones: data design, keeping state consistent, and making sure the system holds up when someone else touches it.

That same instinct carries over into how I think about AI. Whether a system is useful depends on what data the model sees, what state it keeps between turns, and where you draw the line between deterministic rules and generated words. In CareLoop SG, rules make every care decision while the model only handles language. That is the kind of software I want to build: tools reliable enough that people trust the answer and act on it.
